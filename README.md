A vintage travel poster for **VELMORA** — a fictional island where the aurora pools in a still lagoon, watched over by a white lighthouse on a black-rock islet. A place that isn't there, drawn to make you want to go.

The poster is a single image, `entry.png` (1024×1024, under the 1 MiB gate), and a tiny Python program, `main.py`, copies it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
